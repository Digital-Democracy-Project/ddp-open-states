## Deploy steps (from ddp-sync's own README "Deployment" section)

**EC2 civic (systemd, canonical scheduler for cloud jobs):**
```bash
cd /home/ubuntu/ddp-sync
git pull origin main
source .venv/bin/activate
pip install .
sudo systemctl restart ddp-sync
```

**Mac Studio (system LaunchDaemon, runs the actual OpenStates scrapes) -- needs an admin
account, README's own words, not something either agent session can do without sudo:**
```bash
cd /Users/agentsmith/Developer/repos/ddp-sync && git pull origin main
sudo launchctl kickstart -k system/com.ddp.ddp-sync
curl -s http://localhost:8001/ddp-sync/v1/schedule    # verify the six OpenStates jobs
```

Both hosts run their own independent scheduler (no leader election) and both need this pulled --
README: "A change to this repo should be deployed to **both** targets."
